## 📖 About

**Random Stock Simulator**는 실제 주식 시장 데이터를 사용하지 않고,
무작위로 변동하는 가상의 주가를 기반으로 주식을 사고팔 수 있는 간단한 웹 프로젝트입니다.

5개의 종목이 각각 설정된 초기 가격에서 시작하며,
시간이 지남에 따라 주가가 랜덤하게 변동합니다.

사용자는 주식을 매수하거나 매도하면서
보유 현금과 주식 평가액의 변화를 확인할 수 있습니다.

## 🎮 How It Works

1. 설정된 초기 자금으로 시뮬레이션을 시작합니다.
2. 5개 종목의 주가가 지속적으로 랜덤하게 변동합니다.
3. 원하는 종목을 현재 가격에 매수할 수 있습니다.
4. 보유하고 있는 주식을 현재 가격에 매도할 수 있습니다.
5. 가격 변동에 따라 보유 자산의 가치가 계속 변화합니다.
